5 Nguyên tắc kiến trúc bất biến
Những quyết định này không được thay đổi sau khi đã chọn
Rủi ro lớn nhất không phải chọn sai technology — mà là vi phạm một trong 5 nguyên tắc này trong quá trình phát triển.
🏗
1. API-first, không có exception
Mọi business logic phải đi qua API. UI chỉ là một client như bất kỳ client nào khác. Không được phép viết logic trong Controller, Blade, hay Livewire component. Khi bạn cần thay Vue bằng React 5 năm nữa — chỉ mất 3 tháng thay frontend, không phải rewrite toàn bộ.
⚡
2. Event-driven cho mọi side effect
Khi Invoice được submit, KHÔNG được gọi trực tiếp sendEmail(), updateStock(), postGL(). Thay vào đó dispatch InvoiceSubmitted event. Mọi module subscribe và tự xử lý. 5 năm nữa thêm AI module — chỉ cần thêm listener, không sửa một dòng code cũ nào.
🗃
3. Metadata-driven đến cùng
Càng nhiều thứ định nghĩa qua metadata (DocType, DocField, Permission, Workflow), platform càng sống lâu. Business user có thể thêm custom field, tạo workflow mới, đổi permission — không cần developer, không cần deploy. ERPNext sống 15 năm vì nguyên tắc này.
🤖
4. MCP-ready từ architecture
Model Context Protocol là chuẩn mở đang trở thành cách AI agents tương tác với hệ thống. Nếu platform expose MCP endpoints ngay từ đầu, 5 năm nữa bất kỳ AI agent nào cũng có thể tạo Invoice, approve workflow, query báo cáo — mà không cần viết thêm một dòng integration code nào.
📋
5. Audit trail mọi thứ, từ ngày 1
Mọi thay đổi data phải được ghi lại: ai sửa, khi nào, trước/sau là gì, từ IP nào. Không phải vì compliance — mà vì 2 năm nữa sẽ có lúc bạn cần biết tại sao số liệu sai. Và khi không có audit trail, bạn không thể biết. Thêm sau rất khó — làm từ đầu rất dễ.

class DocTypeRegistry { private static array $cache = []; /** Load schema từ Redis cache, fallback về DB */ public static function get(string $doctypeName): DocType { if (isset(self::$cache[$doctypeName])) { return self::$cache[$doctypeName]; } $cacheKey = "doctype.schema.{$doctypeName}"; $schema = Cache::remember($cacheKey, now()->addHours(24), fn() => DocType::with(['fields', 'permissions']) ->where('name', $doctypeName) ->firstOrFail() ); self::$cache[$doctypeName] = $schema; return $schema; } /** Đăng ký controller cho module */ public static function register(string $doctype, string $controllerClass): void { app()->bind("doctype.controller.{$doctype}", $controllerClass); } public static function getController(string $doctype): DocumentController { $key = "doctype.controller.{$doctype}"; return app()->has($key) ? app($key) : app(DefaultDocumentController::class); } /** Clear cache khi DocType thay đổi */ public static function clearCache(string $doctype): void { Cache::forget("doctype.schema.{$doctype}"); unset(self::$cache[$doctype]); } }
DocumentService — Generic CRUD
app/Core/Services/DocumentService.php
class DocumentService { public function __construct( private PermissionService $permission, private AuditService $audit, ) {} public function save(string $doctype, array $data, User $user): array { $schema = DocTypeRegistry::get($doctype); $controller = DocTypeRegistry::getController($doctype); $doc = new Document($schema, $data); // Permission check $this->permission->assertCanWrite($doctype, $user); // Lifecycle hooks $controller->validate($doc); $controller->beforeSave($doc); // Persist $isNew = empty($data['name']); $result = DB::table($schema->getTable()) ->updateOrInsert(['name' => $doc->name], $doc->toArray()); // Audit trail $this->audit->log($doctype, $doc->name, $isNew ? 'create' : 'update', $data, $user); // After save hook + event $controller->afterSave($doc); Event::dispatch(new DocumentSaved($doctype, $doc, $user)); return $doc->toArray(); } public function submit(string $doctype, string $name, User $user): array { $schema = DocTypeRegistry::get($doctype); $controller = DocTypeRegistry::getController($doctype); if (!$schema->is_submittable) { throw new LogicException("{$doctype} không thể submit"); } $doc = $this->get($doctype, $name, $user); DB::table($schema->getTable())->where('name', $name)->update(['docstatus' => 1]); $controller->onSubmit($doc); $this->audit->log($doctype, $name, 'submit', [], $user); Event::dispatch(new DocumentSubmitted($doctype, $doc, $user)); return $doc->toArray(); } }

class PermissionService { public function can(string $doctype, string $action, User $user): bool { $cacheKey = "perm.{$user->id}.{$doctype}.{$action}"; return Cache::remember($cacheKey, 300, fn() => DocPermission::where('doctype', $doctype) ->where('role', $user->getRoleForTenant()) ->where($action, true) ->exists() ); } /** Filter fields theo permlevel của user */ public function filterFields(array $data, DocType $schema, User $user): array { $maxLevel = $this->getPermLevel($schema->name, $user); $allowedFields = $schema->fields ->where('permlevel', '<=', $maxLevel) ->pluck('fieldname') ->toArray(); return array_intersect_key($data, array_flip($allowedFields)); } public function assertCanWrite(string $doctype, User $user): void { if (!$this->can($doctype, 'write', $user)) { throw new AuthorizationException( "Không có quyền write {$doctype}" ); } } }

MCP Layer — AI-native từ Architecture
Model Context Protocol · AI agents tương tác với platform như một human user
MCP (Model Context Protocol) là chuẩn mở của Anthropic, đang trở thành cách AI agents tương tác với external systems. Platform có MCP server → bất kỳ AI agent nào cũng có thể dùng platform của anh mà không cần custom integration.

class MCPServer { /** List available tools — tự động từ registered DocTypes */ public function tools(): array { $doctypes = DocType::all(); return $doctypes->flatMap(fn($dt) => [ [ 'name' => "get_{$dt->name}", 'description' => "Lấy danh sách {$dt->label}", 'inputSchema' => $this->buildListSchema($dt), ], [ 'name' => "create_{$dt->name}", 'description' => "Tạo mới {$dt->label}", 'inputSchema' => $this->buildCreateSchema($dt), ], // submit, cancel nếu DocType is_submittable ...$dt->is_submittable ? [[ 'name' => "submit_{$dt->name}", 'description' => "Submit {$dt->label}", 'inputSchema' => ['type' => 'object', 'properties' => ['name' => ['type' => 'string']]], ]] : [], ])->values()->toArray(); } /** Execute tool call từ AI agent */ public function execute(string $tool, array $input, User $agent): array { [$action, $doctype] = explode('_', $tool, 2); return match($action) { 'get' => app(DocumentService::class)->list($doctype, $input, $agent), 'create' => app(DocumentService::class)->save($doctype, $input, $agent), 'submit' => app(DocumentService::class)->submit($doctype, $input['name'], $agent), default => throw new InvalidArgumentException("Unknown tool: {$tool}"), }; } }

class AuditService { public function log( string $doctype, string $docname, string $action, array $data, User $user, ?array $before = null ): void { // Ghi vào MySQL (realtime lookup) DB::table('audit_logs')->insert([ 'id' => Str::uuid(), 'doctype' => $doctype, 'docname' => $docname, 'action' => $action, 'user_id' => $user->id, 'user_email' => $user->email, 'ip_address' => request()->ip(), 'user_agent' => request()->userAgent(), 'before_data' => $before ? json_encode($before) : null, 'after_data' => json_encode($data), 'diff' => $before ? json_encode($this->diff($before, $data)) : null, 'created_at' => now(), ]); // Push sang ClickHouse async cho analytics PushAuditToClickHouse::dispatch([ 'doctype' => $doctype, 'action' => $action, 'user_id' => $user->id, 'ts' => now(), ]); } private function diff(array $before, array $after): array { $changes = []; foreach ($after as $key => $value) { if (array_key_exists($key, $before) && $before[$key] !== $value) { $changes[$key] = ['from' => $before[$key], 'to' => $value]; } } return $changes; } }

Milestone anh cần đạt ở tháng thứ 3
Sau 3 tháng, platform phải có: DocType Engine chạy được + 1 module (CRM hoặc HR) live cho ít nhất 1 subsidiary của Pascal Group. Nếu không đạt được milestone này, architecture cần được review lại.
Dấu hiệu architecture đang sai hướng
✗ Module A import class từ Module B trực tiếp
✗ Business logic nằm trong Controller thay vì Service
✗ Không có event khi document thay đổi state
✗ Permission check nằm rải rác, không tập trung
✗ Tenant data có thể query từ tenant khác
✗ Xây microservice khi chưa cần scale
Dấu hiệu đang đúng hướng
✓ Thêm module mới không cần sửa Core
✓ Thêm listener mới không cần sửa controller cũ
✓ Thêm DocType mới qua UI, không deploy code
✓ AI agent có thể dùng platform qua MCP ngay
✓ Mọi thay đổi data đều có audit trail
